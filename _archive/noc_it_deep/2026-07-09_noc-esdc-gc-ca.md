# National Occupational Classification
The research phase for the 2026 National Occupational Classification (NOC) is now complete. To learn more about the upcoming update, we invite you to visit the _Participate in NOC consultation_ section, which includes a summary of the planned changes for NOC 2026 Version 1.0.
The National Occupational Classification (NOC) is Canada’s national system for describing occupations.  
You can search the NOC to find where an occupation is classified or to learn about its main duties, educational requirements or other useful information.

## Search tips
Not familiar with the NOC structure? No worries, you can search the NOC by typing in job titles using the search tab "Search by job title".
You are familiar with the NOC structure and want to access a given NOC code quickly? Search the NOC using the tab “Search by NOC code”.
Still cannot find your NOC code?
Try using job titles similar to yours in the tab “Search by job title” or else, try our advanced search tool.
