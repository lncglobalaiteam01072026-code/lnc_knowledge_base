# Welcome to the Occupational and Skills Information System
The Occupational and Skills Information System (OaSIS) provides a comprehensive framework of the skills, abilities, personal attributes, knowledge, and interests typically required for 900 Canadian occupations. It also offers context about the work environments where these occupations are performed.
